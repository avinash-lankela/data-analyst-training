# Retail Sales Performance - Exploratory Data Analysis (EDA)

## Project Objective
The objective of this project is to analyze retail sales data, clean the dataset, perform business analysis, detect outliers, and create visualizations to support business decisions.

## Dataset Description
The dataset contains more than 500 retail sales records with the following columns:
- Order_ID
- Order_Date
- Customer
- Region
- Category
- Product
- Quantity
- Unit_Price
- Salesperson
- Revenue
- Month

The dataset includes:
- Missing values
- Duplicate records
- Outliers
- One full year of sales data

## Libraries Used
- Python
- Pandas
- Matplotlib
- NumPy

## Analysis Steps
1. Created the retail sales dataset
2. Loaded the dataset using Pandas
3. Displayed the first 10 rows
4. Checked number of rows and columns
5. Checked column names and data types
6. Identified missing values
7. Identified and removed duplicate records
8. Handled missing values
9. Created Revenue and Month columns
10. Performed business analysis
11. Detected outliers
12. Created charts and saved them in the charts folder
13. Generated the summary CSV file

## Key Findings
- Calculated total company revenue
- Found monthly revenue trends
- Identified the highest revenue region
- Identified the highest-performing category
- Found the top 5 products by revenue
- Evaluated salesperson performance
- Identified the highest revenue customer
- Displayed the largest order record
- Detected revenue outliers
